# Export vectors

What the two desktop exports must produce. `MARKDOWN.md` is the binding Markdown layout (S-5), `markdown-cases.json` its cases and `budget-review.md` a complete golden file that an app must reproduce byte for byte. `export-vectors.json` pins how the audio of an exported Cassini file is sized from its sources (the `match-source` policy, D8). Run by GNOME and Mac. Vendor the folder at a pinned commit of this repo with the SHA-256 of each file, as GNOME's `tests/export/UPSTREAM.json` does.
