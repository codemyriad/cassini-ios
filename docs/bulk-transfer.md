# Several notes and ZIP (D96)

Contract and copy: `codemyriad/cassini-ux` at `4d577376f6360ed352fa75307f4dc47890ed9858`, decisions D96 and the shared string IDs listed in [the string pin](shared-strings-pin.md). No shared files were edited.

The existing multi-file picker now also accepts ZIP. A selection runs sequentially with a cancel action and the shared nonzero summary parts. A cancelled batch keeps completed notes. A new selection arriving while cancellation unwinds starts as a fresh batch. The native iOS picker has no custom filter-caption API; its permitted content types include audio/Opus/Ogg/ZIP and the shared filter description is the Import button's accessibility hint.

Every archive's directory and local headers are validated before entry bodies are read. There are at most 2,000 entries and 20,000,000,000 uncompressed bytes; compression above 100:1, encryption, absolute paths or parent components refuse the whole archive. Nested archives are ignored and counted unsupported. Each audio entry has the normal 4 GiB import limit; an oversized entry fails individually. ZIP64, stored entries and raw deflate are supported. Unsupported compression methods are refused as unreadable archives using the shared damaged-archive copy.

Entries stream in 64 KiB chunks to generated names under one UUID staging directory, retaining their original base name only as display metadata. Even a 65,535-byte ZIP name never becomes a filesystem path. CRC, actual lengths, size limits and available space are checked during extraction. All bodies are staged and checked before that archive inserts notes, so a later corrupt body cannot leave earlier entries imported. The normal import service then provides content detection, decoding and digest deduplication. Unrecognized headers get the normal platform audio probe. Completion/cancellation removes the batch's own directory; the empty parent is retained to avoid racing another batch's directory creation, and launch clears interrupted staging behind the ready fence.

The Library export chooser offers all live-library notes or selected notes, with active captures disabled. Transcribed notes use the existing complete portable-document export, keeping versions/provenance. Notes without words keep their original audio bytes and extension, including a completed transcription with no speech. A ZIP has one stored/uncompressed entry per note and no manifest. Names follow `ExportNames`, with case-insensitive collision detection and numeric ` (2)`, ` (3)` suffixes. Work is linear apart from bounded filename collision lookup; nothing reads an entire recording into memory. The share sheet owns the resulting archive's lifetime and removes it on dismissal; failure/cancellation removes all intermediate files.

Cancel reaches native encoding/decoding, inspection, portable verification/sealing and ZIP chunk reads/writes. Progress uses the canonical current-item ordinal and an indeterminate spinner, so preparation/packing never pretends to have completed. Tests use real synthetic PCM and Ogg reads gated by events, not elapsed-time assertions or sleeps. No recording is played through audio output.
